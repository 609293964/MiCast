# MiCast：给每只小米音箱单独调音，还能多音箱同步播放

家里有几台不同型号的小米音箱，想把手机或电脑的声音投过去，再按每只音箱的听感分别调音？MiCast 是运行在飞牛 fnOS 上的音频投放应用。NAS 接收 AirPlay / DLNA 音频后送到选定的音箱；你可以给每只音箱单独设置 EQ、响度和音量，也能让多台音箱同步播放，或把两只音箱组成左右声道。

> **一句话介绍：**把手机、电脑的声音投到小米音箱，并按每只音箱的听感单独调音。

**版本说明：**飞牛应用商店目前上架的是 **0.2.2**；**0.2.5 已提交商店审核**，目前也可从项目下载 `.fpk` 安装包。下方界面截图展示的是项目新版，部分调音界面和功能与商店版不同。

## 能做什么

- **手机、电脑直接投放**：提供经典 AirPlay 和 DLNA 接收入口。iPhone、iPad、Mac 可使用 AirPlay；支持 DLNA 的播放器也可以把音频投进来。
- **多台音箱一起播放**：同一音源可以送到多台小米音箱，支持跨型号组合。组播时可逐台校准延迟，让播放更同步，并调整响度、音量和静音状态。
- **两台音箱组成左右声道**：指定左、右音箱，MiCast 拆分声道并同步输出。
- **按音箱调声音**：为单台音箱或组合设置 EQ、声道和播放目标。
- **在飞牛端查看状态**：管理音箱、查看播放链路，使用测试音频和运行日志排查连接问题；也可以通过飞牛移动端打开 MiCast 操作。

## 商店版 0.2.2 与项目版 0.2.5 有什么区别

0.2.2 已支持 AirPlay / DLNA 投放、多音箱同步、立体声组合和单音箱 EQ。0.2.5 在此基础上，主要有这些变化：

- **调音更直观**：新增可视化 EQ 曲线和调音页实时频谱预览；连续拖动 EQ 控制点时也做了防抖处理，减少编码器反复重启。
- **播放更稳定**：加深 AirPlay 抖动缓冲，给丢包重传更多时间，改善网络抖动时的跳拍；同时修复了部分 DLNA 播放问题。
- **账号维护更省心**：改进小米扫码登录；短期凭证失效时会尝试自动换新，确实需要重新登录时会弹出扫码入口。
- **更新与排查更方便**：加入 GitHub 更新检测和升级入口，改进链路诊断；调音和播放页面也有持续完善。

如果主要想先体验投放和多音箱功能，可以从飞牛应用商店安装 0.2.2；想使用新版调音界面和上述修复，可以从项目下载 0.2.5 安装包。0.2.5 已提交飞牛应用商店审核，上架时间以商店实际显示为准。

## 在飞牛上怎么用

1. 在飞牛应用中心直接搜索并安装商店版 MiCast（0.2.2），或从项目下载 [MiCast 0.2.5 的 fnOS 安装包 `micast-x86-0.2.5.fpk`](https://github.com/DyMode/MiCast/releases/download/v0.2.5/micast-x86-0.2.5.fpk)，在飞牛中手动安装。
2. 从飞牛桌面或飞牛移动端打开 MiCast。首次进入时，按页面引导设置管理访问方式、扫码连接米家账号，并选择要使用的音箱。
3. 确保 NAS、手机或电脑、音箱处于可互相访问的同一局域网。随后在投放设备上选择 MiCast 的 AirPlay 或 DLNA 入口，开始播放。
4. 想让多台音箱一起响，可以在应用里配置播放目标或立体声组合；组播时可逐台校准延迟，并按实际听感调整响度。

MiCast 的管理页面走 fnOS 统一网关，打开应用即可进入，无需记单独的管理端口。

## 关于 AirPlay 2

fnOS 原生包还提供一个**可选的实验性 AirPlay 2 入口**，默认关闭，可在首次引导或设置中启用。建议先用默认提供的经典 AirPlay / DLNA 入口完成配置和试播；如果需要 AirPlay 2，再自行开启体验。

## 使用前留意

- 当前 fnOS 原生包面向 **x86** 设备，依赖应用中心的 **Python 3.12**。
- 设备发现依赖局域网的 mDNS / SSDP。若 NAS 与手机、音箱之间开启了访客网络隔离，或网络设备拦截组播，投放入口和音箱可能无法被发现。
- 多音箱组播的同步效果会受网络与设备自身缓冲影响。应用提供逐台延迟校准；首次组合后可按实际播放效果调整。
