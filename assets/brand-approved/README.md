# MiCast 图标定稿

用户已确认采用 A1 比例优化对比图右侧版本。

- 矢量母版：`micast.svg`
- 设计预览：`micast-preview.png`（512 × 512，sRGB）
- 比例记录：`proportions.json`
- 背景：陶土红 `#B94B36`，纯色，无渐变。
- 图形：暖白 `#FFF7ED`，两枚错位叠放的音箱，前实后虚。
- 圆角底板占画布 90%，四周透明留白 5%。
- 相对原 A1，图形围绕画布中心放大 8%，再向右移画布宽度的 1%、向上移高度的 0.5%。
- 图形包围盒约占底板宽度 61%、高度 63%。

本目录为唯一的视觉母版。平台导出文件在 `../icons/`，使用 `../export_icons.py` 重新生成；完整资产包为 `../micast-icons.zip`。
不同平台和尺寸采用各自的透明度、线宽和留白适配，保持已确认的配色、组合造型和前实后虚关系。正式文件不带版本号后缀。
