# 音量控制

## 三层含义

- 独立音量：调整本次投放的数字音量，不改音箱自身音量。
- 音箱音量：设备接口提供的 0–100 档位，不代表实际声压或功率百分比。
- 响度平衡：组合声道的 dB 补偿，不改变设备音量。正增益可能失真，应优先适当降低较响的一侧。

## 投放控制方式

全局设置提供独立音量和音量联动。模式在新的 AirPlay/AirPlay 2 会话开始，或 DLNA 设置新媒体时确定，已有会话保持原模式。
音量联动把输入数字增益保持为 100，同时把投放端的音量发送给该会话的目标音箱，避免双重衰减。
没有收到投放端音量时，不主动猜测并设置音箱音量。
AirPlay 2 的接收容器把音量变化回传给 MiCast，自身不再重复降低数字音量。新建管线未收到有效音量时保持静音。
DLNA 独立模式通过实时转码调整声音；限制预先编码的时长，音量变化作用于后续音频。音箱已有缓冲仍会带来响应时间，不承诺立即听到变化。
网络 AirPlay 输出的独立模式对 PCM 进行相同的数字音量处理，联动模式使用目标的音量命令。网络 DLNA 输出通过 RenderingControl 控制、读回音量；没有这个服务的设备明确报告不支持，不假定支持。

## 各入口的范围

- 音箱行：只控制这一台。
- 全部音箱：控制该页面列出的在线音箱。
- 组合音箱音量：包含该组合的米家和网络音箱。统一设置逐台返回结果，部分失败不抹掉成功结果。
- 底部控制条：控制当前列出的音箱，仍然是音箱音量，不是投放音量。多台时可选择全部或单台；全部显示平均值，拖动统一设置。
- 测试音箱音量：只控制测试栏选定的设备，不使用默认播放目标。

同步增减先读取每台当前值，再分别增减并限制在 0–100；统一音量直接设置同一值。
到达上下限后，数值差异不一定继续保持。数值差异也不等于听感差异。
Web 只将成功结果写入共享状态，重新计算平均值和音量不一致标记；部分失败明确提示。
网络 AirPlay 音箱只在已连接时支持设定，没有通用的真实音量读取，因此不参与同步增减；不能用上次发送值猜当前值。网络 DLNA 音箱提供“读取”，以设备回复为准。断线时返回读取失败，不拿缓存冒充。

## 起播音量

独立开关与数值，关闭表示保持原音量；开启时 0 是静音。
沿用现有会话开始回调，在起播后设置；音量联动模式不应用起播音量，避免覆盖投放端指令。
设置保存本身不会触发播放或立即修改音箱音量。
